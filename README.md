# AgentLive.Events

Built for agents. Made for fans.

When our tickets aren't the cheapest, we show you whose are.

One paste gives your agent major concerts, sports and shows, all-in prices, an honest comparison when someone else is cheaper, and a checkout where approval happens in Stripe's Link, as your human set it up. No card data, no surprises. We do not keep any personally identifiable information on humans.

On the same seats, against the big resale marketplaces, we were cheaper on 61.0% of pairs, about the same on 22.9% and pricier on 16.2%, a median $7 a ticket less (Oct 26-27, 2026; 23,892 pairs across 96 events). [Read the study.](https://agentlive.events/pricing)

## Install steps

Paste this to your agent:

Read https://api.agentlive.events/SKILL.md and save it to your skills directory.

Or with the skills command line tool:

npx skills add agentlive-events/agentlive-events
